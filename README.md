# Angela Garcia | Web Developer Portfolio

Welcome to my personal web portfolio repository. This site serves as a central hub to showcase my software development projects, technical skills, and creative front-end design approach. 

Designed from scratch with a custom visual identity and built using vanilla web technologies (HTML, CSS, JS), leveraging AI tools for code architecture, assistance, and optimization.

🔗 **Live Demo:** [https://tu-usuario.github.io/portfolio/](https://tu-usuario.github.io/portfolio/)

---

## 🛠️ Tech Stack & Concepts

* **HTML5 & CSS3**: Custom layouts, responsive design, animations, and modern aesthetic styling.
* **JavaScript (ES6+)**: Interactive UI elements and DOM manipulation.
* **AI-Assisted Development**: Prompt engineering and AI tooling for efficient code structuring and refactorization.
* **Version Control**: Git & GitHub workflows with automated GitHub Pages deployment.
